# HelloNameApp

A minimal Android app:
1. Enter your name.
2. Tap the button.
3. The app says `سلام <name> 👋`.

## APK build
GitHub Actions automatically builds a debug APK on every push to `main` or `master`.
You can also run the workflow manually from the Actions tab.

Artifact name: `HelloNameApp-debug-apk`
APK inside artifact: `app-debug.apk`
